# DB University

Progettazione dello schema di un database universitario (dipartimenti, corsi di laurea, corsi, insegnanti, studenti, esami) più una raccolta di query SQL di esercitazione (filtri, join, aggregazioni).

## Tecnologie

- Documentazione markdown
- SQL
- Diagramma drawio

## Avvio

Le query si eseguono su un database MySQL.
